# JobApplier Roadmap

Our vision is to build the ultimate local-first, privacy-respecting form engine for job hunters. Below is our development timeline.

## Phase 1: Core Scaffolder & Stability (Current)
* [x] Manifest V3 standard compliance.
* [x] Kuhn-Munkres (Hungarian) optimal matching algorithm.
* [x] Dynamic sibling fingerprinting for repeated block clustering.
* [x] Framework-safe DOM setters bypassing React/Angular shadow nodes.
* [x] Drag & drop simulators for file injection.

## Phase 2: Enhanced Customization & UI (Q3 2026)
* [ ] **Local Matching Training:** Allow users to manually override a matched key, saving the custom field mappings locally.
* [ ] **Custom Section Support:** Enable customizable profile categories (e.g., custom skills, hobbies, certificates) mapping to arbitrary selectors.
* [ ] **Dark/Light Themes:** Inject custom user styles to personalize the options dashboard.

## Phase 3: Broad Platform Support (Q4 2026)
* [ ] **Platform Adapter Library:** Write specific adapters for other major Applicant Tracking Systems (ATS) like Taleo, Workable, and Breezy.
* [ ] **Autofill Performance Analytics:** Track match confidence ratios and display success graphs locally in the options panel.

## Phase 4: Encryption & Privacy (Q1 2027)
* [ ] **Encrypted Backup Files:** Password-protect JSON profile backups on export using client-side AES-GCM.
* [ ] **Sandbox Sandbox Constraints:** Fully test browser permission scoping to ensure third-party frame isolation.
