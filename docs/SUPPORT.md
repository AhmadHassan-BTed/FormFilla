- **Feature Requests** — Submit ideas via the [issue tracker](https://github.com/AhmadHassan-BTed/FormFilla/issues) with the `enhancement` label

## Before Opening an Issue

1. Check the [FAQ](#) (coming soon) for common questions
2. Search existing [issues](https://github.com/AhmadHassan-BTed/FormFilla/issues) for similar problems
3. Ensure you're running the latest version from the Chrome Web Store
4. Include your browser version, OS, and steps to reproduce the issue

## Response Times

- **Bug reports:** Typically addressed within 48 hours
- **Feature requests:** Reviewed within 1 week
- **Security vulnerabilities:** Immediate attention (see [Security Policy](SECURITY.md))
