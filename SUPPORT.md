# Support Guide

Need assistance or have questions about JobApplier? Here's how you can find help.

## Documentation

Before raising a support inquiry, please review our comprehensive guide folders:

* **System Design details:** [docs/system-design.md](docs/system-design.md)
* **Extension Matching rules:** [docs/architecture.md](docs/architecture.md)
* **Security & Sandbox controls:** [docs/security-architecture.md](docs/security-architecture.md)

## Asking Questions

If you want to discuss use-cases, request features, or need troubleshooting advice, please use our standard channels:

* **GitHub Issues:** Open an issue with the `question` or `discussion` tag.
* **Email Support:** Reach out directly to **ahmadhassan.bted@gmail.com** for private inquiries.

## Reporting Bugs

To report a bug, please submit an issue using our [Bug Template](.github/ISSUE_TEMPLATE/bug_report.md). Specify browser version, page URLs where matches failed, and console error traces if available.
