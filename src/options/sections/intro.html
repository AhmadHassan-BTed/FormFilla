Welcome to FormFilla

Getting Started with FormFilla

FormFilla is a secure, local-first browser extension designed to eliminate repetitive copy-pasting from job and scholarship applications. It uses a custom fuzzy matching engine to identify labels and autocomplete form fields instantly.

Core Features

  • No AI Required: Operates 100% locally and deterministically. No API keys or remote calls required.
  • Dynamic Lists: Handles repeated application blocks such as education history, experience rows, language levels, and awards.
  • Pakistan CNIC & Scholarship Mappings: Tailored support for South Asia, GKS, and Commonwealth application forms.

1. You Don't Have to Fill Everything

FormFilla is designed to be highly flexible. You only need to fill out the settings or fields that you want to automate. If a field is empty in your profile, the extension simply skips it and leaves the corresponding form input untouched.

2. Power of the Local JSON Profile

Instead of using this dashboard to type out your information, you can manage your data as a clean JSON profile. Go to the Backup & Restore section, download a blank profile template, populate it on your computer, and import it here to load everything at once!

3. How to Fill Application Pages

Open any job board or university scholarship application form. Click the FormFilla icon in the Chrome toolbar, then click "Fill this page". The matching engine will instantly locate form fields and populate them.

4. Dynamic Document Uploads

Store your Resume, Cover Letter, photo assets, SOPs, and research proposals locally in the Documents & Files tab. FormFilla matches file upload buttons on applications and attaches them automatically.
